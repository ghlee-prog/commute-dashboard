# 🌅 iPhone Safari PWA 출근 대시보드 (Naver Direction5 연동)

아이폰 Safari의 **'홈 화면에 추가'** 기능에 최적화된 **PWA 기반 모바일 다크모드 출근 대시보드**입니다.
**네이버 지도 Direction5 API**를 기반으로 실시간 교통상황을 연동하여 출근길 소요시간을 산출합니다.

---

## 📍 기본 출근 경로 설정
- **출발지**: 경기도 광주시 태봉로 225 (`127.2308, 37.3883`)
- **도착지**: 경기도 안양시 학의로 268 (`126.9701, 37.3976`)

---

## 🔑 네이버 지도 API 키 설정 방법

`app/main.py` 파일 최상단에 네이버 클라우드 플랫폼(NCP)에서 발급받은 키를 입력합니다.

```python
# ==============================================================================
# 네이버 클라우드 플랫폼 (NCP) 지도 API 인증 키 설정
# 콘솔 (https://console.ncloud.com/) -> AI·NAVER API -> Application 등록 후
# 'Directions 5' API를 선택하고 발급받은 Client ID와 Client Secret을 아래에 입력하세요.
# ==============================================================================
NAVER_CLIENT_ID = "여기에_Client_ID_입력"
NAVER_CLIENT_SECRET = "여기에_Client_Secret_입력"
```

> 💡 **안내:** API 키를 입력하지 않은 상태(`"키입력"`)에서도 UI가 깨지지 않고 직관적인 안내 문구와 예상 모의 경로 데이터로 안전하게 동작합니다.

## ✨ 주요 대시보드 카드

1. **🚗 출근길 예상 소요시간 (네이버 지도 실시간 교통 기준)**
   - **실시간 빠른길(trafast)**: 제2경인고속도로(안양-성남) 경유 실시간 소요시간 및 정체 반영
   - **무료 우선 도로(traavoidtoll)**: 통행료 0원 우회 경로 비교
   - **대중교통 복합 경로**: 광역버스(1113-1) + 신분당선/4호선
   - **실시간 요금 정보**: 예상 통행료(1,500원), 예상 택시비, 주행 거리(km) 표시
2. **🌤 오늘 날씨 & 대기질 위젯 (경기도 광주시)**
   - 현재 기온, 체감온도, 최고/최저, 미세먼지(PM10)/초미세먼지(PM2.5) 뱃지, 우산 챙기기 알림
3. **💡 스마트홈 조명 원터치 일괄 끄기**
   - **"출근 전 전체 조명 끄기"** 대형 글로우 버튼 및 개별 조명 제어
4. **✅ 출근 전 필수 소지품 체크리스트**
   - 사원증, 에어팟, 지갑, 스마트폰 완충 여부 터치 체크

## 📲 아이폰 Safari '홈 화면에 추가'
1. PC와 아이폰을 **동일한 Wi-Fi**에 연결합니다.
2. `run.ps1`에 표시된 로컬 IP(`http://<PC-IP>:8000`)로 아이폰 Safari에서 접속합니다.
3. Safari 하단 **[공유]** ➔ **[홈 화면에 추가]** ➔ **[추가]**를 누르면 풀스크린 네이티브 앱 형태로 사용할 수 있습니다.
